# CrèmeCraft
Responsive vanilla HTML, CSS and JavaScript bakery concept. Website files are at the repository root. No build dependencies.

Features: scroll reveal, parallax, reduced motion preference, menu category filtering, accessible native photo dialog, three-step validated brief with local reference preview and text download, pausable reviews, social photo strip, contact draft download, illustrative map.

Before commercial launch: provide genuine business address, hours, testimonials and social handles; connect orders, contact delivery and newsletter to a backend. No customer information or uploaded photos is transmitted or stored by this concept. Prices and testimonials are illustrative. Replace reference photos with owned/licensed brand photography; current photo reuse licenses have not been established.
